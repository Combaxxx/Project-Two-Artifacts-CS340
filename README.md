# Project-Two-Artifacts-CS340
### How do you write programs that are maintainable, readable, and adaptable?
When writing programs, I try to keep my code organized so that it is easy to understand, modify, and reuse. One example of this was the CRUD Python module I developed in Project One. Instead of writing MongoDB queries directly into the dashboard application, I created a separate AnimalShelter class that handles the database connection and the Create, Read, Update, and Delete operations. This made the code easier to maintain because the database functionality was separated from the dashboard itself. It also allowed me to reuse the same module throughout the course without having to rewrite the database operations. In the future, I could use a similar CRUD module for other applications that need to manage information stored in MongoDB, such as inventory systems, employee records, or customer databases.

### How do you approach a problem as a computer scientist?
When approaching a programming problem, I start by understanding what the application needs to accomplish and then break the requirements into smaller tasks. For the Grazioso Salvare project, I first needed to understand how the Austin Animal Center data was organized and how to retrieve the information needed to identify potential rescue animals. After setting up the database and creating the CRUD module, I worked on connecting that information to the dashboard and displaying it through interactive components such as a data table and map. This project was different from some of my earlier assignments because I had to make multiple components work together rather than focusing on a single program or algorithm. In future projects, I would use a similar approach by reviewing the client's requirements, designing the database structure, testing queries, and building the application in manageable steps.

### What do computer scientists do, and why does it matter?
Computer scientists design and develop systems that help people solve problems, organize information, and complete tasks more efficiently. Their work is important because many businesses and organizations depend on software to manage large amounts of data and make informed decisions. In the Grazioso Salvare project, the dashboard was designed to help the organization identify animals that could be suitable candidates for rescue training. Instead of manually searching through thousands of shelter records, users could filter the data and view relevant information in an organized dashboard. This could save time, reduce the amount of manual work required, and help the organization make better decisions about which animals to evaluate for training. This project helped me understand how database development and user interfaces can work together to create useful applications that address real-world needs.
